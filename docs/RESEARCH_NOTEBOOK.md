# Research Notebook Control

The canonical research methodology is defined in the PAL repository research/ directory.

For this repository:
- implementation documents describe software state;
- benchmark documents define evaluation methods;
- research notes must distinguish documented design, implementation, observed results and verified claims;
- cultural interpretations remain provisional until independently validated;
- synthetic and in-the-wild speech benchmark results are reported separately.

Use the following order for research changes:
1. identify the claim;
2. locate source evidence;
3. state the epistemic class;
4. run the smallest informative test;
5. preserve raw result;
6. update the claim state;
7. record contradictions and limitations.

No benchmark result is publication-ready without dataset version, sample size, evaluator method, subgroup definition and limitations.
