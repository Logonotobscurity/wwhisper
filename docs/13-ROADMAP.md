# Roadmap

## Phase 0 — Bootstrap
Repository structure, contracts, prompts, tests and environment setup.

## Phase 1 — Semantic core
Conversation state, DAPF, auditor, decision engine and repair.

## Phase 2 — Voice
AssemblyAI WebSocket adapter, session lifecycle, transcripts, audio, tools, interruption and resume behavior.

## Phase 3 — Evidence
Provenance, validated references, corrections and failure cases.

## Phase 4 — Evaluation
Benchmark, four conditions, metrics and regression runner.

## Phase 5 — Demo
Voice UI, telemetry, replay and evaluation display.

## Phase 6 — Hardening
Security, latency, error handling, documentation and submission.

## Later
Large knowledge graphs, broad multilingual coverage, fine-tuning, autonomous high-impact actions and large multi-agent orchestration.
