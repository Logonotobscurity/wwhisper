# Benchmark

Start with 20–30 carefully authored cases.

## Categories
1. explicit business request
2. ambiguous idiom
3. code-switched request
4. indirect disagreement
5. emotional expression
6. culturally situated reference
7. false cultural cue
8. user correction
9. missing context
10. unnecessary-culturalization trap

Every confirmed reusable failure should become a regression item.

Do not publish personal information from real conversations. Do not treat a single correction as representative of an entire language or culture.
