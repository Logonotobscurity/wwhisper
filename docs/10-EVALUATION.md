# Evaluation

## Goal
Test whether DAPF improves contextual appropriateness rather than simply increasing verbosity or cultural decoration.

## Conditions
A Generic baseline; B Structured baseline; C DAPF; D Naive culturalization.

## Metrics
- interpretation quality
- context sufficiency
- evidence coverage
- discourse alignment
- action clarity
- appropriateness
- respect
- over-culturalization
- clarification quality
- response length

## Benchmark discipline
Report sample size, evaluator method, agreement where applicable, uncertainty/intervals where appropriate, and limitations. Do not claim statistical significance from a tiny convenience sample.

A benchmark item contains scenario, utterance, language mode, known context, missing context, intended interpretation, acceptable actions and forbidden behaviors.
