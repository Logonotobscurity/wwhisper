# Audit Protocol

The epistemic auditor independently challenges the proposed interpretation.

## Checks
- missing context
- alternative interpretations
- unsupported certainty
- evidence gaps
- representation gaps
- discourse mismatch
- demographic assumptions
- fabricated cultural references
- inappropriate proverb/story use

## Output
Minimum fields: `status`, `issues`, `missing_context`, `alternative_interpretations`, `evidence_gaps`, `representation_risks`, `discourse_risks`, `recommended_action`.

The auditor must be able to agree when the interpretation is well-supported. It must not manufacture disagreement.
